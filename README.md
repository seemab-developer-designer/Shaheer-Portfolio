# 🎬 Shaheer — Video Editor Portfolio

A modern cyberpunk-inspired portfolio website designed for **Shaheer**, a professional Video Editor. Built with clean HTML, CSS, JavaScript and Bootstrap, the portfolio combines cinematic visuals with a futuristic UI to create a memorable browsing experience.


---

## ✨ Overview

This portfolio was designed to present Shaheer's work in a way that reflects the quality of his editing. Rather than using a traditional portfolio layout, the website follows a **Cyberpunk × GTA Vice City** inspired aesthetic with premium typography, glassmorphism, neon accents and cinematic layouts.

The entire website is lightweight, responsive and built without any frontend frameworks.

## ⚙ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/shaheer-portfolio.git
```

Open the project folder:

```bash
cd shaheer-portfolio
```

Run using Live Server or simply open `index.html` in your browser.
